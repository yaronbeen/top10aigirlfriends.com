# Top 10 AI Girlfriends

Static review website for `top10aigirlfriends.com`.

## Build

```bash
npm install
npm run build
```

Generated output is written to `/home/yaron/top10aigirlfriends.com/dist/`.

## Preview

```bash
npm run dev
```

## Content

Rankings, reviews, categories, and blog post definitions live in `/home/yaron/top10aigirlfriends.com/content/site-data.mjs`.
