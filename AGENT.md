# Purpose & Context

`top10aigirlfriends.com` is a static, content-heavy review website for adult AI girlfriend and AI companion services. The target audience is 40+ men who want a clear buying guide rather than meme-heavy Gen Z copy.

# Architecture / Design

The site is generated by a Node script from centralized content data.

```text
/home/yaron/top10aigirlfriends.com/content/site-data.mjs
        |
        v
/home/yaron/top10aigirlfriends.com/scripts/build-site.mjs
        |
        v
/home/yaron/top10aigirlfriends.com/dist/*.html
```

The design direction is dark, premium, glossy, and card-based, inspired by Candy.ai's polished companion gallery pattern without copying assets.

# Runbook / Operations

Install dependencies:

```bash
npm install
```

Build the site:

```bash
npm run build
```

Preview locally:

```bash
npm run dev
```

Generated output lives in `/home/yaron/top10aigirlfriends.com/dist/`.
